🐛 TROUBLESHOOTING:

Problem: SQL script shows errors
Solution: This is normal! Errors like "already exists" are OK.
         Just wait for it to finish.

Problem: Can't login after signup  
Solution: Check if email confirmation is enabled in Supabase.
         Go to: Authentication → Settings → Email Auth

Problem: Can't access admin panel
Solution: Run the bootstrap_first_admin() command in SQL Editor
